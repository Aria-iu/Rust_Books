# Rust 学习书目索引更新设计

## 目标

将仓库从仅存放书籍文件的集合，补充为一个可维护的 Rust 学习索引：读者无需下载仓库中的书籍，即可按学习方向找到合法、公开的学习资源。

## 范围

- 以 README 为入口，新增按发布时间倒序的书目表；2026 年资源排在最前，其次是 2025 年。
- 每项至少包含：名称、年份/版本、简要概要、适用方向与人群、官方或作者授权的访问链接。
- 仅收录可公开访问、由官方、作者或项目组织发布的资源。链接会标明「在线阅读」或「下载」。
- 不下载、不新增、不提交 PDF、EPUB 或其他书籍二进制文件。
- 保留既有仓库内容，不重命名或删除已有书籍文件。

## 书目选择与来源规则

优先加入在 2025–2026 年有正式发布、更新或可核验新版的资料；不足的方向用仍在维护的官方 Rust 资料补全。每个链接应直接指向出版方、作者、Rust 官方文档或对应开源项目，而非第三方聚合/盗版站。

## 文档结构

README 由三部分组成：

1. 简短说明：仓库索引不包含新增书籍文件，且只列合法公开来源。
2. 「2026 → 2025 → 持续维护的官方资料」倒序表格：读者可快速比较内容与用途。
3. 按方向的阅读路径：入门、异步/并发、Web、嵌入式、CLI、性能与工具链。

## 验证

- 使用 Markdown 结构检查，确认所有新增条目都有概要、方向和链接。
- 对每个外部链接做 HTTP 可达性检查；无法稳定直接验证的链接不纳入。
- 用 `git diff --check` 检查空白问题，并确认暂存内容不包含 PDF/EPUB 等书籍文件。

## 非目标

- 不镜像、转载或提供受版权保护书籍的非授权下载地址。
- 不修改已有书籍二进制文件。
- 不构建自动抓取或下载工具。
